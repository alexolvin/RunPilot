## API update timeout (DEFECT)

`POST /api/v1/nodes/{host}/update` — синхронный: ждёт завершения self-update
узла (скачивание бинарника + doctor + рестарт). При длительном обновлении
таймаут HTTP-клиента → 504.

Причина: `triggerNodeUpdate` использует `r.Context()` (таймаут клиента).
Исправление: асинхронный update (немедленный 202 + фоновое ожидание) или
увеличенный таймаут для update-команды.

Не исправлено в рамках W12: требует изменения API-контракта (202 vs 200)
и тестирования на стенде с вторым узлом.
