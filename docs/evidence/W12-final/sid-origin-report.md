# Происхождение sid W_EZPODRYS

**Дата:** 2026-10-09

## Формат sid

Сиды генерирует только координатор: `sid.New()` → 10 символов Crockford base32
(алфавит `0123456789ABCDEFGHJKMNPQRSTVWXYZ`, без I, L, O, U).

## Анализ W_EZPODRYS

`W_EZPODRYS` содержит подчёркивание `_`, которого нет в алфавите Crockford base32.
Функция `sid.Valid("W_EZPODRYS")` возвращает `false`.

## Вывод

W_EZPODRYS **не мог** быть создан через API — API генерирует sid только через
`sid.New()`, который даёт только валидные символы. Сид был вставлен в БД
прямой записью SQL (не через API).

## Защита

Добавлена функция `sid.Valid()` для проверки формата. Тест `TestValid`
покрывает случай W_EZPODRYS (ожидаемый результат: `false`).
