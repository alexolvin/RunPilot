## Дефекты, найденные и исправленные в ходе W3 (до финального прогона)

Финальные снимки ниже — чистые (19.3 = 0 находок). В ходе итераций были найдены и
исправлены (все — в этом же коммите W3):

1. **htm-разметка**: компоненты рендерились как литеральные теги `<App/>`/`<LoginView/>`
   (htm — шаблонные литералы, компонент = `<${Comp}/>`) → пустая страница. Исправлено
   `web/app/main.js`, `web/app/views/login.js`.
2. **Порядок CSS**: `layout.css` грузился до `components.css`, базовые правила
   (`.sidebar{display:flex}`, `.bottom-tabs{display:none}`) перебивали телефонные
   media-запросы → сайдбар накрывал контент, нижние вкладки не показывались. Исправлено
   порядком `<link>` (tokens → components → layout) и базовым `display:none` вкладок в
   `components.css`.
3. **Телефонный топбар** (390 px) переполнен: заголовок обрезан, подзаголовок в 4 строки,
   «Новая сессия» 26 px. Упрощён (10.3): заголовок + статус + иконки; интерактивы ≥44 px.
4. **Контраст тёмной темы** (axe serious): белый на акценте `#3B82F6` = 3.68 < 4.5
   (кнопки/иконки) и активная вкладка `#3B82F6` на `#1E293B` = 3.96 < 4.5. Исправлено
   токенами: `--color-on-accent:#0F172A` (тёмная) и `--color-accent-text:#60A5FA` (тёмная).
5. **Шрифты**: `document.fonts.check` без `load()` возвращал false для неиспользуемого
   mono (страница входа) → конвейер явно запрашивает оба семейства (19.3.7).

Golden-база: `test/visual/golden/` (10 файлов, первый прогон W3; diff повторного прогона
0.00–0.13 % ≤ diff_max).
