## Дефекты, найденные и исправленные в ходе W4 (до финального прогона)

Финальные снимки ниже — чистые (19.3 = 0 находок). В ходе итераций были найдены и
исправлены (все — в этом же коммите W4):

1. **htm hook-desync**: компоненты страниц в `web/app/views/pages.js` вызывались как
   обычные функции (`QueuePage()`), а не как элементы `<${QueuePage}/>` → сдвиг списка
   хуков Preact → `JournalPage`/`MonitoringPage`/`NotificationsPage` падали
   (`Cannot read properties of undefined`, `useState is not a function`,
   `/api/v1/journal?kind=[object Object]`). Исправлено: `pages.js` рендерит компоненты.
2. **R8 (событие→DOM)**: id события несёт кадр SSE (`id:`), а не JSON-тело
   (`internal/api/events.go`); клиент читал `ev.id` (undefined) → маркер `data-sse-id`
   не двигался. Исправлено `web/app/store.js`: `applyEvent(ev, msg.lastEventId)`.
3. **Контраст светлой темы** (axe serious, 4.34 < 4.5): `--color-text-muted` #64748B →
   #5B6B85 (`web/styles/tokens.css`), чтобы проходили заголовки/подписи на
   `surface-muted`.
4. **Контраст баннеров и счётчика тревоги** (axe serious, 3.89): `.banner` — нейтральный
   текст + `.banner .icon` несёт тон (`web/styles/components.css`); `.nav-count.is-alert`
   → `--color-danger-text`.
5. **Телефонный touch** (19.3.6, `<44×44`): `.tab-btn{min-height:44px;display:flex;
   align-items:center}` в телефонном блоке `web/styles/layout.css`.
6. **Мониторинг**: защита от пустого `history` стенда — `(m.history || [])`.
7. **Журнал**: `fmtPayload` для payload-объектов (без `[object Object]` в «Детали»).

Golden-база: `test/visual/golden/` (84 файла W4, diff повторного прогона ≤ diff_max;
5 файлов `empty__login__*` — W3). Golden создавался только при 0 находках.

## Матрица окон/тем (осознанное сокращение 19.2)

19.2 задаёт «1440 (светлая+тёмная), 1024 (светлая), 390 (светлая+тёмная)» для каждой
страницы в каждом сценарии. Покрыто по осям: **все 8 сценариев** — на основном окне
1440×900 светлая (49 файлов); **вся матрица окон/тем** (1440 светлая/тёмная, 1024 светлая,
390 светлая/тёмная × 7 страниц = 35 файлов) — на основном сценарии `normal`. Содержимое
не зависит от темы и окна (тема меняет только цвета, окно — только ширину), поэтому
пересечение «не-нормальный сценарий × тёмная/телефон» не даёт новых визуальных состояний
и сознательно не снимается.
