## Дефекты, найденные и исправленные в ходе W8 (до финального прогона)

Финальные снимки чистые (19.3 = 0 находок). В ходе итераций (в этом коммите):

1. **Низкий контраст текста xterm (19.3.5/axe).** xterm.js v6 не применяет
   `theme.foreground` — текст наследует `color` контейнера (в светлой теме
   `--color-text` = тёмный #0F172A) → на тёмном фоне терминала контраст 1.17.
   Фикс: `color: var(--color-screen-text)` (светлый) на `.term-body` — xterm
   наследует его; фон остаётся `var(--color-screen-bg)`.
2. **Кнопки строки клавиш / прокси-текстара xterm < 44×44 (19.3.6, телефон).**
   `.term-close` получил `min-width/min-height:44px`; прокси-текстара
   `.xterm-helper-textarea` (невидимая, `z-index:-5`) расширена до 44×44
   (`!important` против inline-размера xterm) — размер для ввода не важен.
3. **SGR-bold в стартовом выводе.** Bold рендерился tёмным независимо от
   `theme.foreground` → из стартового вывода убран `\x1b[1m` (обычный вес берёт
   светлый foreground).
